Hallpay is a self-hosted web service created by Nicholas Chapman at St. Andrew's School in Middletown, DE, USA over the course of one semester, authentically made without AI.

To use:

First, install packages/prerequisites found in the app.js file as well as node.js
Second, set up a google app password and paste it into your password file.
Third, you can set up custom domains however you like (optional)
Fourth, open a terminal and type "node app.js" and it will be self hosted on your local IP on port 3008
